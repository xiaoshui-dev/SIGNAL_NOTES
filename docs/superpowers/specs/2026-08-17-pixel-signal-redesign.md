# Signal Notes 像素信号整站改造设计

## 1. 目标

将现有科技博客改造成具有像素语言、设计感、科技感和质感的完整产品，同时保留长文阅读效率与后台操作效率。视觉需要高端、开放、活泼，但不得退化为复古游戏皮肤或堆满装饰的展示页。

改造范围覆盖：

- 根路径介绍页。
- 博客列表、分类、标签、归档、搜索、作者、关于、联系、隐私和状态页。
- 文章阅读、评论、相关推荐与分享海报。
- 后台登录、仪表盘、文章编辑、分类标签、媒体、评论、反馈、订阅、用户、设置、日志与备份。
- 账户姓名、作者身份、头像上传与 DiceBear Pixel Art 兜底。
- 桌面端与移动端。

现有路由、内容模型、表单能力、SMTP、备份和部署方式保持可用；本次不改变博客的信息架构。

## 2. 已选视觉方向

选定方向为 **Signal Terminal / 信号终端**。

主要参考：

- [Textmode Overlay](https://extension.textmode.art/)：精密黑白像素排版、纵向章节索引、终端式控制与高对比信息层级。
- [Price Adapter](https://www.priceadapter.com/)：真实图像的单色抖动处理、旧显示器式构图和数字档案质感。
- [Landing Love - Peter Oravec](https://www.landing.love/sites/peteroravec/)：像素互动的开放性与生命力；只借鉴动感，不采用游戏地图结构。

当前站点的大图、中文内容和酸性绿色继续作为品牌资产。参考仅用于设计方法，不复制第三方品牌、文案、图像或代码。

## 3. 核心原则

1. **像素是系统，不是贴纸**：字体、边框、图像、光标反馈、索引与动效采用同一套 4/8 像素节奏。
2. **内容优先**：中文正文继续使用适合长文的非像素字体，像素字体只承担品牌标题、导航、标签、数字和短操作文案。
3. **中性底色承载高级感**：黑、炭灰、冷白为主要画布；荧光绿、信号橙和数字蓝只用于状态、强调与分类，不做单色主题。
4. **真实素材优先**：保留真实主板、工作台与文章图片；重点图片制作独立的低分辨率抖动版本，正文原图保持可检查性。
5. **活泼来自反馈**：通过像素擦除、索引跳动、按钮压下、图片分辨率切换和滚动状态增加生命力，不靠漂浮装饰。
6. **后台更密，前台更有呼吸**：公共页面强调沉浸与阅读，后台强调扫描、比较和重复操作。

## 4. 视觉系统

### 4.1 色彩

| Token | 用途 | 固定值 |
| --- | --- | --- |
| Pixel Black | 深色主背景 | #090D0B |
| Carbon | 深色次级表面 | #141A16 |
| Cold Paper | 阅读背景 | #F3F5F0 |
| Pixel White | 深色文字与高亮 | #F9FBF7 |
| Acid Signal | 主操作、在线与选中 | #B9FF66 |
| Signal Orange | 警告、关键变化、分享 | #FF6D3A |
| Digital Blue | 信息、链接与辅助分类 | #64A8FF |
| Muted Gray | 次级文字与分隔 | #8C958E |

颜色必须使用语义 token，不在组件里散落硬编码。深浅模式都以中性色为主，避免绿色铺满整个界面。

### 4.2 字体

- 中文品牌标题、英文标签与数字信息：固定使用 `@fontsource/fusion-pixel-12px-proportional-sc@5.3.0`（OFL-1.1），仅用于短文本。
- 中文正文与密集后台：使用 Noto Sans SC。
- 文章主标题与长文小标题：公共阅读页面使用 Noto Serif SC，避免长文出现低清阅读感。
- 单个页面最多同时出现两类字体：公共阅读页面为 Fusion Pixel + Noto Serif SC，后台为 Fusion Pixel + Noto Sans SC。

字体必须本地托管或固定版本，不依赖运行时第三方字体请求。

### 4.3 几何与组件

- 主要网格以 8px 为基准，细节允许 4px。
- 卡片圆角不超过 4px；大多数区块使用分隔线和留白，不做浮动卡片。
- 按钮使用直角或 2px 圆角，图标来自现有 Lucide 库。
- 焦点态使用 2px Acid Signal 外框，不能只靠颜色变化。
- 进度、状态和数字使用固定宽度，动态内容不得导致布局跳动。
- 像素角、扫描线和抖动纹理只作为真实组件或图像资产的一部分，不使用大面积噪点覆盖正文。

## 5. 页面设计

### 5.1 介绍页

- 首屏保持全宽沉浸，不放入卡片。
- 顶部导航改为终端状态栏：站点名、版本/日期、文章/主题/关于和进入博客。
- 主标题使用大尺寸中文像素字，分三行以内，首屏同时露出下一段内容。
- 主板照片保留真实主体，增加一份黑白抖动版本；指针移动或滚动时在原图与抖动图之间做局部解析切换。
- 主 CTA 为 Acid Signal 实心按钮，次 CTA 为线框按钮。
- 右侧或底部显示章节索引 01-05，当前章节以反色方块显示。
- 下方主题、精选、作者和页脚改为全宽 band，不新增装饰性卡片。

### 5.2 博客列表与索引页

- 列表头使用巨大标题加一列简短说明，保留现有编辑式构图。
- 分类筛选改为可横向滚动的终端命令条，数量使用等宽数字。
- 文章列表采用“编号 / 图像 / 元数据 / 标题”的扫描结构；桌面为横向行，移动端堆叠。
- 图片默认真实清晰，悬停或键盘聚焦时短暂显示抖动版本并恢复。
- 空状态、连接失败和分页使用同一终端状态语言。

### 5.3 文章页

- 阅读区使用 Cold Paper，正文最大宽度保持舒适行长。
- 页头、面包屑、作者、阅读时间、分享和目录使用像素信息层。
- 桌面右侧显示章节进度索引；移动端缩为顶部阅读进度条。
- 代码块使用深色终端表面，复制按钮为图标并保留提示。
- 分享海报新增像素模板，同时保留二维码可扫性和标题边界测试。
- 评论、相关文章与作者区使用分隔线组织，不嵌套卡片。

### 5.4 后台

- 左侧导航改为深色命令栏，选中项使用 Acid Signal 反色块。
- 顶栏显示数据库状态、当前账户姓名和头像，不再硬编码演示姓名。
- 仪表盘统计使用共享网格和细分隔线，不把每个数字做成浮动卡片。
- 文章列表、媒体、评论和用户管理提高信息密度，保持可扫描列宽。
- 编辑器主区继续以写作为中心，右侧设置形成固定宽度终端检查面板。
- 表单控件必须保留清晰标签、错误说明、禁用、保存中和成功状态。

### 5.5 账户与作者头像

- 账户设置允许修改当前账户姓名并上传头像。
- 上传图片优先显示；未上传时由本地 DiceBear Pixel Art 根据账户姓名稳定生成。
- 后台、文章署名、作者页和公开 API 使用同一作者身份。
- 新文章由后端绑定当前登录账户；旧的演示作者数据升级为当前管理员身份。
- 头像文件复用媒体上传校验；被账户引用的媒体禁止误删。

## 6. 动效与交互

- 首屏进入：标题按 4-8px 像素块擦除显现，图片解析度从低到高切换，时长不超过 700ms。
- 滚动：章节索引即时更新；内容只使用短位移与遮罩，不使用长时间淡入。
- 导航与按钮：悬停显示 1-2px 像素偏移，按下时下沉 2px。
- 文章图像：悬停在清晰图和抖动图之间切换，键盘聚焦获得同等反馈。
- 后台状态：保存、发布、上传和测试邮件使用内联进度与结果，不用无限旋转作为唯一反馈。
- 所有动画支持 prefers-reduced-motion；禁用动画后信息和操作保持完整。

## 7. 数据与兼容

- 新增账户头像字段和文章作者关联，保留作者姓名快照作为删除账户后的兜底。
- 新增 Flyway 迁移，兼容现有 MySQL 部署。
- 不修改已经执行过的历史迁移文件。
- 公共接口继续返回现有字段，并新增 authorId 与 authorAvatarUrl；旧前端字段不立即删除。
- 站点设置中的作者简介继续作为公开简介，账户姓名成为文章署名的权威来源。

## 8. 资产策略

- 真实文章图片和现有品牌照片继续使用。
- 为首屏和必要缩略图生成独立的像素/抖动位图，不在运行时把整张照片模糊或拉伸。
- DiceBear 使用本地依赖，不请求公共头像接口。
- 不创建装饰性 SVG、CSS 图画、emoji 或无意义占位图。
- 清理前通过源码引用、构建产物、路由、部署清单和 Git 跟踪状态五项检查确认无用文件。

## 9. 响应式与无障碍

- 验收宽度至少覆盖 1440、1024、768、390 和 360。
- 首屏在所有视口露出下一段内容，不出现文字与按钮重叠。
- 导航、筛选、编辑器工具栏和固定索引在窄屏时换行或折叠。
- 交互区域最小 44px，文本对比度满足 WCAG AA。
- 不依赖像素色块表达唯一含义；状态同时提供文字或图标。
- 图片必须有 alt；纯装饰纹理不进入可访问树。

## 10. 验收与测试

- 前端单元测试覆盖作者身份、头像优先级、DiceBear 稳定种子、分享 URL、路由和自动保存。
- 后端测试覆盖账户资料、作者绑定、旧数据迁移、媒体引用保护和公开文章字段。
- 前端构建和后端测试全部通过。
- 浏览器逐页检查介绍页、博客、文章、分类、标签、搜索、状态页、后台仪表盘、文章编辑、媒体、用户和设置。
- 桌面与移动截图检查无重叠、无裁切、无空白画布和无不可读像素文字。
- 参考图与实现截图在同一视口对比，design-qa.md 最终必须为 passed。
- 检查浏览器控制台无新增错误。
